# Basic Password Verifier

This is a small Python project I created while learning Python. The goal was to practice working with strings, conditional statements, and user input by building a basic password verification program.

## What It Does

The program checks a password against the conditions defined in the code and determines whether it meets the required criteria.

This project helped me practice:

- Taking input from the user.
- Working with strings.
- Using conditional statements.
- Combining multiple conditions to validate input.
- Writing simple programs to solve practical problems.

## Requirements

- Python 3

No additional packages are required if the program uses only Python's standard library.

## How to Run

Clone the repository:

```bash
git clone https://github.com/hexinitz/basic-password-verifier.git
cd basic-password-verifier
```

Run the Python script:

```bash
python3 main.py
```

Replace `main.py` with the actual filename of your Python script if it is named differently.

Follow the prompts in the terminal to test the program.

## What I'm Learning

This project is part of my journey of learning Python through small, practical programs. I'm using these projects to understand programming fundamentals and gradually improve my code.

## Limitations

This is a basic learning project, not a complete authentication or password security system. Passing the checks does not guarantee that a password is secure.

For real applications, password verification should be part of a properly designed authentication system with secure password hashing and other appropriate protections.
